# SL-BOT

## Setup

1. Create a `.env` file in the project root.
2. Add your bot token inside it:

```
DISCORD_TOKEN=your_bot_token_here
```

3. Do not commit `.env` to version control. `.gitignore` already excludes it.

4. Install dependencies:

```
pip install -r requiremets.txt
```

5. Run the bot:

```
python main.py
```
